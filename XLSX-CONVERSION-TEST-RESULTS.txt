Validated locally with the bundled pdf_convert.py converter and the three supplied sample PDFs.

PersonalStatement_MC-PUBHL(2).pdf

- Output contains an Info sheet stating that no structured tables were detected

Frontend/backend checks
- convert-from-pdf.html contains XLSX as a conversion option
- Frontend sends the selected format to /api/pdf-to-xlsx through the shared conversion endpoint logic
- app.py exposes POST /api/pdf-to-xlsx
- requirements.txt includes openpyxl
- app.py and pdf_convert.py pass Python syntax compilation

Important design rule
PDF -> XLSX is treated as table/data extraction, not full-page document recreation. This avoids producing meaningless spreadsheets for certificates/forms that do not contain structured tabular data.

Note: the local environment used for this validation did not have Flask installed, so a live Flask HTTP request was not executed here. The converter function itself and the generated XLSX files were validated directly.
