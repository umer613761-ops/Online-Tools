Scanned-page strategy:
- Render the actual PDF page at a fixed DPI so coordinates match the Word page.
- Preserve scanned artwork as page image segments.
- Detect the prominent ruled marks table on the HSSC page.
- White out only that table rectangle in the surrounding scan.
- Rebuild the table as editable Word table cells with text, borders and header shading.
- Keep photographs, signatures, logos, handwritten/cursive material and other artwork in the scan image.

Important:
- Scanned certificate page text outside reconstructed tables remains image content. TXT/HTML use OCR separately.
- This is a hybrid editable reconstruction, not a claim that every pixel of a scanned certificate can become native Word objects.
